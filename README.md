## 🚀 Projetos

### 🚦 Smart Inclusive Traffic Light

**Projeto Final — Técnico em Desenvolvimento de Sistemas (SENAI)**

Meu principal projeto desenvolvido durante o curso até o momento.

Um sistema de semáforo inteligente criado com Arduino, sensores e programação em C/C++, com foco em acessibilidade e adaptação do tempo de travessia para diferentes necessidades.

O projeto utiliza identificação de perfis através de sensores e botões, permitindo diferentes configurações de funcionamento, incluindo alertas sonoros e tempos personalizados para pedestres.

### Tecnologias utilizadas:

- Arduino
- C/C++
- Tinkercad
- Eletrônica básica
- Lógica de programação
